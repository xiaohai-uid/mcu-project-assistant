# ADR 0002: 会员分层与联网搜索架构

引入用户分层（免费/会员）和联网比价搜索能力，重构推荐流水线。

## 决策

用户分三层：
- **免费用户**: 使用向导模式、内置配件库（静态价格）、模板代码生成。可使用有限免费搜索配额。
- **订阅会员**: 按月/年付费，解锁 WebSearchService 完整功能（爬虫比价）、专业模式（自定义配件/引脚/代码）。
- **自带 Key 用户**: 绑定自己的 AI 和/或搜索 API Key，可不受会员限制使用对应功能。系统零成本运营。

新增 WebSearchService，支持三种搜索源（淘宝/1688、综合搜索引擎、专业元器件商城）。免费用户触发搜索时检查配额，会员无限制，自带 Key 用户使用其 Key。

RecommendationService 在生成 ComponentList 时检查 Membership 状态：免费版仅查询内置 SQLite 库；会员版同步调用 WebSearchService 获取实时比价并价格替换。

## 考虑的方案

- **纯免费 + 捐赠** → 无法覆盖爬虫服务器和 LLM API 成本
- **仅订阅制** → 轻度用户不想月付，按量更适合他们
- **选中方案**: 订阅 + 按量 + BYO Key 三轨并行

## 后果

- 正向：三种付费模式覆盖不同用户群体，降低入门门槛
- 正向：自带 Key 模式让高级用户零成本使用，同时减少系统 LLM 开销
- 代价：引入支付、配额管理、Key 加密存储等基础设施复杂度
- 代价：爬虫需要维护反封锁策略和定期更新
